# 問題の監修（GitHub 版）

更新：2026-10-27（`python tools/make_review_pages.py` で作り直す。手で編集しない）

## 監修のしかた

1. 下の表から領域を選び、ページを開く。
2. 問題文・選択肢・正答と、各選択肢の根拠カードを読み、問題として成り立っているか確認する（正答が1つに決まるか、誤りの選択肢が確かに誤りか、紛らわしい表現がないか）。
3. 問題がなければ「**まとめて承認する**」を開き、監修者名を書いて送信する。直すべき問題は一覧から行を消す。
4. 直すべき問題は「**この問題を監修する**」から「修正が必要」を選び、修正案を書いて送信する。
5. 数分で自動的に記録され、サイトでも「監修済み」として出題される。

承認したあとに問題文や根拠カードが変わると、自動で「監修前」に戻り、再監修の対象になる。
